Design decision

Engineering Evidence makes the target developer role, concrete code, database work and GitHub visible immediately. AI Product Engineer foregrounds the human–AI working loop but risks implying more direct AI-review history than the sources establish. A was selected for ODNOS role alignment, first-screen clarity, technical credibility, recruiter scanning, source prominence and project discoverability. Both share responsive, low-motion recruiter actions. These are design judgments, not measured recruiter-study results.
